IMPROVED PACKAGERS PORTED
Version 2.0.1 | Schedule I 0.4.6f13 IL2CPP

Original author: GuysWeForgotDre
Compatibility port maintained by: GSVS UK ACM

This independently maintained port restores Improved Packagers on the f13
IL2CPP game build. It lets assigned Packagers follow each Packaging Station's
pack/unpack mode, move loose output to storage and load vehicles at Loading Bays.

REQUIREMENTS
------------
- Schedule I 0.4.6f13 IL2CPP
- MelonLoader 0.7.0 Open-Beta
- Mod Manager & Phone App (REQUIRED):
  https://www.nexusmods.com/schedule1/mods/397

INSTALLATION
------------
1. Close the game.
2. Open the Schedule I installation folder, then open its Mods folder.
3. Remove old/original copies named ImprovedPackagers.dll,
   ImprovedPackagersPORTED.dll or Main-ImprovedPackagers.dll.
4. Install MelonLoader and Mod Manager & Phone App if needed.
5. Copy ImprovedPackagersPORTED.dll from this ZIP into the Mods folder.
6. Launch the game and make sure Improved Packagers PORTED is enabled in the
   in-game Mod Manager.

Keep only one Improved Packagers DLL installed. Do not install this ZIP inside
another folder and do not keep the original mod beside the port.

USAGE
-----
Assign a Handler/Packager to a Packaging Station. Set the station to the needed
pack or unpackage mode. The worker will use the station and move its output via
the normal storage/transit workflow.

COMPATIBILITY
-------------
- Built and play-tested on Schedule I 0.4.6f13 IL2CPP.
- Tested both by itself and with HWE 2.2.3 enabled.
- No new Mono compatibility claim is made by this port.
